## ✨ Overview

**Emmy Noether Math Visualizer** is an interactive Python application designed to make mathematical concepts easier to explore through visualization.

Instead of simply working with equations on paper, the project allows users to **see how mathematical functions behave**, experiment with parameters, and develop a deeper intuition for mathematical concepts.

The project is inspired by **Emmy Noether**, one of the most influential mathematicians of the 20th century, whose work transformed modern mathematics and theoretical physics.

---

## 🎯 Goals

The main goals of this project are:

- 📈 Visualize mathematical functions dynamically.
- 🧠 Encourage conceptual understanding through experimentation.
- 🔢 Make abstract mathematical concepts more intuitive.
- 🖥️ Provide an accessible and interactive learning experience.
- 🐍 Apply Python programming to mathematical exploration.
- 🌟 Connect mathematics, technology, and education.

---

## 🚀 Features

### Function Visualization

Plot mathematical functions and observe their behavior on a coordinate plane.

### Parameter Exploration

Modify function parameters and instantly see how the graph changes.

### Mathematical Analysis

Explore concepts such as:

- Functions
- Transformations
- Intercepts
- Domains and ranges
- Tangent lines
- Asymptotes
- Polynomial functions
- Exponential functions
- Logarithmic functions
- And more...

### Interactive Interface

The application allows users to enter mathematical expressions and interact with their visualizations without requiring advanced programming knowledge.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/emmy-noether-math-visualizer.git
cd emmy-noether-math-visualizer
```

### 2. Install the dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python src/main.py
```

## 🧮 Example

A function such as:

```text
f(x) = x² - 4x + 3
```

can be visualized to explore its:

- Roots
- Vertex
- Axis of symmetry
- Intersections
- Overall shape

The goal is to turn mathematical expressions into something that can be **seen, manipulated, and understood**.

## 👩‍🔬 Inspired by Emmy Noether

Emmy Noether was one of the most influential mathematicians of the 20th century. Her work fundamentally shaped abstract algebra and mathematical physics.

This project takes inspiration from her mathematical legacy by combining **mathematics and computation** to explore mathematical relationships visually.

> **The objective is not only to obtain an answer, but to understand why the mathematics behaves the way it does.**

## 📚 Educational Purpose

This project was created as an educational and exploratory tool.

It is intended to support students in developing mathematical intuition rather than replacing traditional mathematical reasoning.

The visualizer encourages users to experiment with functions, observe patterns, and connect algebraic expressions with their graphical representations.
